Tool offset

[ToolOffsetData]

TOOLOFST.TXT

Program

[Program]

ALL-FLDR.TXT

When bit 6 (NPE) of parameter No.3201 is 0, sequence number "N" etc. cannot be written after the block of M02, M30, M99 of the NC program. When bit 6 (NPE) of parameter No.3201 is set to 0 and the following NC program is written, an error occurs in the N30 block and the programs after that are not written.

Example)

                   O0100 ;

                   N10G0X1000Y100 ;

                   N20M30 ;

                   N30 ;
